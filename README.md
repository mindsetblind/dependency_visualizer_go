# depviz — визуализатор графа зависимостей pip-пакетов

## Общее описание

`depviz` — консольный инструмент на Go, который строит граф зависимостей
Python-пакетов (формат pip, репозиторий PyPI) и визуализирует его.
Готовые менеджеры пакетов и библиотеки для получения зависимостей не
используются — только стандартная библиотека Go.

Практическая работа № 2 по дисциплине «Конфигурационное управление»,
вариант 29. Каждый этап работы находится в своей ветке:

| Этап | Ветка | Содержание | Статус |
|------|-------|------------|--------|
| 1 | `stage-1` | минимальный прототип с конфигурацией | готов |
| 2 | `stage-2` | сбор данных: прямые зависимости с PyPI | — |
| 3 | `stage-3` | граф зависимостей (BFS с рекурсией), тестовый режим | — |
| 4 | `stage-4` | обратные зависимости | — |
| 5 | `stage-5` | визуализация: D2, изображение, ASCII-дерево | — |

## Требования

- Go 1.27 или новее
- bash (для `run.sh` и демонстрационных скриптов)

## Структура проекта

```
.
├── go.mod                  модуль depviz, без внешних зависимостей
├── run.sh                  сборка и запуск программы
├── src/

│   └── config/config.go    разбор и проверка параметров

```

## Параметры командной строки

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `-package` | строка | — (обязательный) | имя анализируемого пакета |
| `-repo` | строка | `https://pypi.org/pypi` | URL репозитория или путь к файлу тестового репозитория |
| `-test-mode` | флаг | выключен | режим работы с тестовым репозиторием: `-repo` — путь к файлу |
| `-ascii-tree` | флаг | выключен | вывод зависимостей в виде ASCII-дерева |
| `-max-depth` | целое | `3` | максимальная глубина анализа зависимостей |
| `-h` | флаг | — | справка по параметрам |

Параметры можно записывать как `-package flask`, `--package flask` или
`-package=flask`.

### Проверка параметров

При ошибке программа печатает сообщение в stderr и завершается с кодом 1.

| Параметр | Ошибка |
|----------|--------|
| `-package` | не задан или пустой; недопустимые символы (разрешены латинские буквы, цифры, `.`, `-`, `_`; начало и конец — буква или цифра) |
| `-repo` (обычный режим) | пустой; не начинается с `http://` или `https://`; нет адреса сервера |
| `-repo` (с `-test-mode`) | файл не существует; указана папка, а не файл |
| `-max-depth` | не целое число; меньше 1 |
| прочее | неизвестный параметр; параметр без значения; лишние аргументы без параметра |

## Сборка и запуск

Запуск через скрипт (собирает программу и запускает её):

```bash
./run.sh -package flask
```

Сборка исполняемого файла вручную:

```bash
go build -o depviz ./src
./depviz -package flask
```

## Тесты

```bash
go test ./...
```

Подробный вывод каждого теста:

```bash
go test -v ./...
```

Демонстрация обработки всех ошибок этапа 1:

```bash
./scripts/demo_stage1.sh
```

## Примеры использования

На этапе 1 программа выводит параметры, заданные пользователем, в
формате `ключ=значение`.

Только имя пакета, остальные параметры по умолчанию:

```
$ ./run.sh -package flask
package=flask
repo=https://pypi.org/pypi
test_mode=false
ascii_tree=false
max_depth=3
```

Все параметры:

```
$ ./run.sh -package requests -repo https://pypi.org/pypi -ascii-tree -max-depth 2
package=requests
repo=https://pypi.org/pypi
test_mode=false
ascii_tree=true
max_depth=2
```

Тестовый репозиторий:

```
$ ./run.sh -package A -test-mode -repo repo.txt
package=A
repo=repo.txt
test_mode=true
ascii_tree=false
max_depth=3
```

Примеры ошибок:

```
$ ./run.sh
ошибка: не задано имя пакета (-package)

$ ./run.sh -package fl@sk
ошибка: недопустимое имя пакета "fl@sk"

$ ./run.sh -package flask -repo ftp://pypi.org
ошибка: URL репозитория "ftp://pypi.org" должен начинаться с http:// или https://

$ ./run.sh -package A -test-mode -repo missing.txt
ошибка: файл тестового репозитория "missing.txt" не найден

$ ./run.sh -package flask -max-depth 0
ошибка: глубина 0 недопустима: должна быть не меньше 1

$ ./run.sh -package flask -max-depth abc
ошибка: неверные аргументы: invalid value "abc" for flag -max-depth: parse error

$ ./run.sh -package flask -depth 2
ошибка: неверные аргументы: flag provided but not defined: -depth

$ ./run.sh -package flask extra
ошибка: лишние аргументы без флага: extra
```
